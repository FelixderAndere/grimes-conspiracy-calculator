# grimes-conspiracy-calculator

A website calculator implementation of the research paper _On the Viability of Conspiratorial Beliefs_ by David Robert Grimes.

## Usage

Open `[github.pages Website](https://felixderandere.github.io/grimes-conspiracy-calculator/)` in a browser.

The calculator supports:
- Forward leak probability with stable `N`.
- Forward leak probability with changing `N(t)` using a Gompertz survival model.
- Reverse calculations for maximum `N` or maximum `t` from a target `L(t)`.
- Plotly visualization of `L(t)` and `N(t)`.
